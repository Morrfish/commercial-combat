# Commercial Combat

Playtest build of the Commercial Combat digital card battler: Story Mode, Quick Combat played on the printed game board, The Showroom (collection and deck building), and the Gameplay & Rulebook.

Play it in a browser. Open `index.html`, or use the GitHub Pages link for this repository. Nothing needs to be installed. Progress is saved in the browser you play in.

This is a work-in-progress playtest. The rules, rewards and story are drafts.
